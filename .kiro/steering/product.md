# Product Overview

C# Refactoring Assistant is an AI-powered web application for semantic C# code refactoring through natural language commands.

## Core Functionality

- Natural language interpretation of refactoring commands via LLM (OpenAI/Ollama)
- Semantic C# code analysis and editing through Serena MCP Server
- Automatic Git checkpoint creation before each modification
- Project state rollback to any previous checkpoint
- Dialogue history management per project
- Web-based chat interface for user interaction

## Target Users

Developers working on C# projects who want to perform code refactoring using natural language commands instead of manual editing.

## Key Value Proposition

Combines the power of LLM understanding with semantic code manipulation tools to enable safe, trackable refactoring operations with automatic version control integration.
