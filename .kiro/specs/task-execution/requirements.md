# Требования: Автоматическое выполнение задач

## Обзор
Система автоматического планирования и выполнения задач с использованием двух моделей:
- **DeepSeek (reasoning)** - анализирует контекст и tasks, создает детальный план
- **Llama (execution)** - выполняет задачи по плану, создает файлы и код

## Пользовательский сценарий

1. Пользователь создает группу диалогов и заполняет:
   - Requirements (требования)
   - Design (проектирование)
   - Tasks (список задач)

2. При открытии диалога в группе с заполненным Tasks:
   - Справа от кнопки "Отправить" появляется кнопка "Задачи"

3. При нажатии на кнопку "Задачи":
   - DeepSeek анализирует контекст (Requirements, Design, Tasks)
   - Создает детальный план выполнения с подзадачами
   - Для каждой задачи указывает:
     * Структуру папок
     * Список файлов
     * Код для каждого файла

4. Интерфейс разделяется:
   - **Левая панель** (30-40%): План задач с аккордеоном
   - **Правая панель** (60-70%): Чат с моделью

5. Левая панель содержит:
   - Кнопка "Запустить все задачи" (сверху)
   - Список задач и подзадач (аккордеон)
   - Для каждой задачи:
     * Название и описание
     * Код (свернут по умолчанию)
     * Кнопка "Запустить" / Loader / "Остановить"
     * Статус выполнения

6. При выполнении задачи:
   - Llama читает план задачи
   - Создает структуру папок и файлов
   - Пишет код в файлы
   - Отчитывается о прогрессе в чате справа
   - Обновляет статус задачи слева

## Технические требования

### Backend

#### Новый API endpoint: POST /api/dialogues/{id}/plan-tasks
**Запрос:**
```json
{
  "dialogueId": 123,
  "groupContext": {
    "requirements": "...",
    "design": "...",
    "tasks": "..."
  }
}
```

**Ответ:**
```json
{
  "planId": "uuid",
  "tasks": [
    {
      "id": 1,
      "title": "Создать структуру проекта",
      "description": "...",
      "folders": ["Models", "Services", "Controllers"],
      "subtasks": [
        {
          "id": 1,
          "title": "Создать Models/User.cs",
          "code": "public class User { ... }",
          "filePath": "Models/User.cs"
        }
      ]
    }
  ]
}
```

#### Новый API endpoint: POST /api/dialogues/{id}/execute-task
**Запрос:**
```json
{
  "dialogueId": 123,
  "taskId": 1,
  "planId": "uuid"
}
```

**Ответ:** Streaming через WebSocket с прогрессом выполнения

#### Новый API endpoint: POST /api/dialogues/{id}/stop-task
Остановка выполнения текущей задачи

### Frontend

#### Новые компоненты:
1. **TaskButton** - кнопка "Задачи" рядом с "Отправить"
2. **TaskPanel** - левая панель с планом задач
3. **TaskAccordion** - аккордеон для задач и подзадач
4. **TaskExecutor** - управление выполнением задач

#### Состояния задач:
- `pending` - ожидает выполнения
- `running` - выполняется
- `completed` - выполнена
- `failed` - ошибка
- `stopped` - остановлена

### Модели

#### DeepSeek (Planning)
- Модель: deepseek-r1:7b или deepseek-reasoner
- Роль: Анализ и планирование
- Промпт: Детальный план с структурой и кодом

#### Llama (Execution)
- Модель: llama3.1:8b
- Роль: Выполнение задач
- Промпт: Создание файлов и кода по плану

## UI/UX требования

### Кнопка "Задачи"
- Видна только если Tasks заполнено
- Иконка: Material Icon `assignment`
- Цвет: синий (#007bff)
- Позиция: справа от кнопки "Отправить"

### Левая панель задач
- Ширина: 35% экрана
- Фон: #f8f9fa
- Скроллинг: независимый от чата
- Анимация появления: slide-in слева

### Аккордеон задач
- Свернут по умолчанию
- Иконка: `expand_more` / `expand_less`
- Код: моноширинный шрифт, подсветка синтаксиса (опционально)

### Кнопки управления
- "Запустить все": зеленая, сверху панели
- "Запустить": зеленая, возле каждой задачи
- "Остановить": красная, появляется при выполнении
- Loader: Material Icons `sync` с анимацией вращения

### Чат справа
- Ширина: 65% экрана
- Сообщения от модели с префиксом `[Task Execution]`
- Автоскролл к последнему сообщению

## Приоритеты

### MVP (Минимальный функционал):
1. ✅ Кнопка "Задачи" появляется при наличии Tasks
2. ✅ DeepSeek создает план задач
3. ✅ Левая панель с аккордеоном
4. ✅ Запуск одной задачи через Llama
5. ✅ Отображение прогресса в чате

### Фаза 2:
1. Запуск всех задач по цепочке
2. Остановка выполнения
3. Обработка ошибок
4. Сохранение плана в БД

### Фаза 3:
1. Подсветка синтаксиса кода
2. Редактирование плана перед выполнением
3. История выполнения задач
4. Экспорт плана

## Технические детали

### Промпт для DeepSeek (Planning):
```
Ты - архитектор проекта. Проанализируй контекст и создай детальный план выполнения задач.

КОНТЕКСТ:
Requirements: {requirements}
Design: {design}
Tasks: {tasks}

ФОРМАТ ОТВЕТА (JSON):
{
  "tasks": [
    {
      "title": "Название задачи",
      "description": "Описание",
      "folders": ["папка1", "папка2"],
      "subtasks": [
        {
          "title": "Подзадача",
          "filePath": "путь/к/файлу.cs",
          "code": "код файла"
        }
      ]
    }
  ]
}
```

### Промпт для Llama (Execution):
```
Выполни следующую задачу:

ЗАДАЧА: {task.title}
ОПИСАНИЕ: {task.description}

ПОДЗАДАЧИ:
{subtasks}

Создай все необходимые папки и файлы. Отчитывайся о каждом шаге.
```

## Безопасность

1. Валидация путей файлов (PathValidator)
2. Ограничение на размер создаваемых файлов
3. Проверка прав доступа к директориям
4. Таймаут выполнения задачи (5 минут)

## Метрики успеха

1. Время создания плана < 30 секунд
2. Успешное выполнение задачи > 90%
3. Корректность созданного кода > 85%
4. Удобство интерфейса (user feedback)
