# Требования: Группы диалогов с контекстом

## Цель
Реорганизовать систему диалогов, добавив группировку с возможностью хранения контекста (requirements, design, tasks) для каждой группы.

## Функциональные требования

### 1. Модель данных
- ✅ Создана модель `DialogueGroup` с полями:
  - Id, Name, ProjectPath
  - Requirements, Design, Tasks (nullable text)
  - CreatedAt, IsCollapsed
  - Связь один-ко-многим с Dialogue
- ✅ Обновлена модель `Dialogue` с полем `DialogueGroupId` (nullable)
- ✅ Создана миграция базы данных

### 2. Backend API
- ✅ GET `/api/dialogue-groups` - получить группы для выбранного проекта
- ✅ POST `/api/dialogue-groups` - создать группу
- ✅ PUT `/api/dialogue-groups/{id}` - обновить название и состояние сворачивания
- ✅ PUT `/api/dialogue-groups/{id}/context` - обновить контекст (requirements, design, tasks)
- ✅ DELETE `/api/dialogue-groups/{id}` - удалить группу
- ✅ POST `/api/dialogue-groups/{groupId}/dialogues` - создать диалог в группе

### 3. Frontend UI

#### 3.1 Список диалогов (аккордеон)
- [ ] Заменить плоский список диалогов на аккордеон групп
- [ ] Каждая группа - элемент аккордеона с возможностью свернуть/развернуть
- [ ] Внутри группы - список диалогов
- [ ] Диалоги без группы отображаются в отдельной секции "Без группы"

#### 3.2 Управление группами
- [ ] Кнопка "Добавить группу диалогов" (вместо "Создать диалог")
- [ ] Рядом с названием группы три кнопки:
  - ➕ Добавить диалог в группу
  - 🗑️ Удалить группу
  - 📄 Открыть модальное окно контекста

#### 3.3 Модальное окно контекста
- [ ] Три textarea для ввода:
  - Requirements (Требования)
  - Design (Проектирование)
  - Tasks (Задачи)
- [ ] Кнопка "Сохранить"
- [ ] Кнопка "Отмена"

#### 3.4 Стили
- [ ] CSS для аккордеона
- [ ] CSS для кнопок управления группой
- [ ] CSS для модального окна контекста

### 4. JavaScript логика
- [ ] Функция `loadDialogueGroups()` - загрузка групп с диалогами
- [ ] Функция `createDialogueGroup()` - создание группы
- [ ] Функция `deleteDialogueGroup(groupId)` - удаление группы
- [ ] Функция `toggleGroup(groupId)` - свернуть/развернуть группу
- [ ] Функция `createDialogueInGroup(groupId)` - создать диалог в группе
- [ ] Функция `openContextModal(groupId)` - открыть модальное окно контекста
- [ ] Функция `saveGroupContext(groupId)` - сохранить контекст группы
- [ ] Обновить `renderDialogueList()` для отображения аккордеона

## Технические детали

### Структура данных группы
```json
{
  "id": 1,
  "name": "Фича авторизации",
  "projectPath": "D:\\SITES\\My\\test_CodeDev",
  "requirements": "# Требования\n...",
  "design": "# Проектирование\n...",
  "tasks": "# Задачи\n...",
  "createdAt": "2026-02-27T15:00:00Z",
  "isCollapsed": false,
  "dialogues": [
    { "id": 1, "createdAt": "..." },
    { "id": 2, "createdAt": "..." }
  ]
}
```

### Обратная совместимость
- Диалоги без группы (DialogueGroupId = null) отображаются в секции "Без группы"
- Существующие диалоги продолжают работать
