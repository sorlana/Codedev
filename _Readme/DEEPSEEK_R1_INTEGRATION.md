# Интеграция DeepSeek-R1

## Обзор изменений

Проект обновлен для использования модели DeepSeek-R1, которая предоставляет более развернутые ответы с рассуждениями вместо лаконичных сообщений о выполнении.

## Что изменилось

### 1. Конфигурация (appsettings.json)
```json
"Llm": {
  "Provider": "Ollama",
  "Ollama": {
    "BaseUrl": "http://localhost:11434",
    "Model": "deepseek-r1:latest"
  }
}
```

### 2. System Prompt (PromptProcessor.cs)

Новый промпт поощряет модель:
- Объяснять понимание задачи
- Описывать план действий
- Комментировать результаты выполнения

**Формат ответа модели:**
1. Понимание задачи: "Я понял, что нужно..."
2. План: "Для этого я сделаю следующее:..."
3. Вызов инструментов (tool calls)
4. Итог: "Готово! Я выполнил... Результат:..."

### 3. Обработка ответов (OllamaLlmService.cs)

DeepSeek-R1 может возвращать **одновременно**:
- Текстовое содержимое (рассуждения)
- Tool calls (вызовы инструментов)

Обновленная логика парсинга:
```csharp
// Сначала извлекаем текст (рассуждения)
if (message.TryGetProperty("content", out var contentProp))
{
    llmResponse.TextContent = contentProp.GetString();
}

// Затем извлекаем tool calls
if (message.TryGetProperty("tool_calls", out var toolCalls))
{
    // Парсинг tool calls
}
```

### 4. Форматирование вывода (PromptProcessor.cs)

Улучшенный формат ответа пользователю:

```
[Рассуждения модели]

📋 Выполнение операций:

✅ Выполнение команды:
   [результат]

✅ Чтение файла:
   [содержимое файла (первые 500 символов)]
```

**Новые функции:**
- `GetFunctionDisplayName()` - человекочитаемые названия функций на русском
- Ограничение длины вывода (500 символов для длинных результатов)
- Эмодзи-индикаторы (✅ успех, ❌ ошибка)

## Преимущества DeepSeek-R1

1. **Прозрачность**: Модель объясняет свои действия
2. **Контекст**: Пользователь понимает, почему выполняется та или иная операция
3. **Отладка**: Легче понять, если модель неправильно поняла задачу
4. **UX**: Более естественное общение вместо сухих технических сообщений

## Пример работы

**Запрос пользователя:**
```
Создай файл test.txt с текстом "Hello World"
```

**Ответ DeepSeek-R1:**
```
Я понял, что нужно создать новый файл test.txt с содержимым "Hello World".
Для этого я использую команду Windows echo для записи текста в файл.

📋 Выполнение операций:

✅ Выполнение команды:
   Команда выполнена успешно
```

## Требования

- Ollama установлен и запущен
- Модель DeepSeek-R1 загружена: `ollama pull deepseek-r1:latest`
- Достаточно RAM для работы модели (рекомендуется 16GB+)

## Альтернативные модели

Если DeepSeek-R1 слишком требовательна к ресурсам, можно использовать:
- `deepseek-r1:7b` - меньшая версия
- `deepseek-r1:1.5b` - минимальная версия
- `llama3.1:8b` - предыдущая модель (без рассуждений)

Изменить модель в `appsettings.json`:
```json
"Model": "deepseek-r1:7b"
```
