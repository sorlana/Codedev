# Few-Shot Learning для улучшения ответов модели

## Проблема

Модель llama3.1:8b давала сухие технические ответы:
```
Выполнено execute_shell_command: Команда выполнена успешно
```

Вместо понятных объяснений:
```
Отлично! Файл text.txt успешно создан с текстом "Привет!". 
Вы можете найти его в текущей директории проекта.
```

## Решение: Few-Shot Learning

### Что такое Few-Shot Learning?

Это техника, когда мы показываем модели примеры желаемого поведения прямо в контексте запроса.

### Реализация

В `PromptProcessor.cs` добавлены примеры диалогов:

```csharp
// Пример 1: Создание файла
User: "Создай файл hello.txt с текстом Hello"
Assistant: "Понял, вам нужно создать файл hello.txt с содержимым \"Hello\".

Я использую команду Windows echo для записи текста в файл. 
Эта команда перенаправит текст в новый файл.

[Сейчас выполню команду...]

Отлично! Файл hello.txt успешно создан с текстом \"Hello\". 
Вы можете найти его в текущей директории проекта."

// Пример 2: Чтение файла
User: "Покажи содержимое файла Program.cs"
Assistant: "Хорошо, я прочитаю содержимое файла Program.cs для вас.

Использую инструмент чтения файлов, чтобы получить содержимое этого файла.

[Читаю файл...]

Вот содержимое файла Program.cs. Это главный файл приложения, 
который содержит точку входа и настройку сервисов."
```

### Дополнительная защита

Добавлен метод `CleanTechnicalJargon()`, который:
- Удаляет технические фразы из ответа модели
- Фильтрует упоминания названий функций
- Очищает технический жаргон

**Фильтруемые фразы:**
- "Выполнено execute_shell_command:"
- "[вызываешь execute_shell_command"
- "execute_shell_command с {"
- И другие технические конструкции

## Структура запроса к модели

```
1. System Message (инструкции)
2. Example User 1 (пример запроса)
3. Example Assistant 1 (пример хорошего ответа)
4. Example User 2 (еще пример запроса)
5. Example Assistant 2 (еще пример хорошего ответа)
6. История диалога пользователя
7. Текущий запрос пользователя
```

## Преимущества

✅ Модель видит конкретные примеры желаемого поведения
✅ Учится на примерах, а не только на инструкциях
✅ Более естественные и понятные ответы
✅ Меньше технического жаргона
✅ Лучшее понимание контекста

## Результат

**Было:**
```
Выполнено execute_shell_command: Команда выполнена успешно
```

**Стало:**
```
Понял, вам нужно создать файл text.txt с текстом "Привет!".

Я использую команду Windows echo для записи текста в файл.

✅ Файл 'text.txt' успешно создан в директории D:\Projects\MyProject

Готово! Файл создан и готов к использованию.
```

## Настройка

Примеры находятся в `Services/PromptProcessor.cs` в методе `ProcessPromptAsync()`.

Вы можете добавить свои примеры для обучения модели специфичному поведению:

```csharp
var exampleUser3 = new Message
{
    Role = "user",
    Content = "Ваш пример запроса"
};

var exampleAssistant3 = new Message
{
    Role = "assistant",
    Content = "Желаемый ответ модели"
};

// Добавить в messagesWithSystem
messagesWithSystem.Add(exampleUser3);
messagesWithSystem.Add(exampleAssistant3);
```

## Важно

- Примеры должны быть реалистичными
- Показывайте желаемый стиль общения
- Не перегружайте контекст (2-3 примера достаточно)
- Примеры учитывают токены в лимите контекста
