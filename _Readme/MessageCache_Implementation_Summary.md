# Реализация MessageCache - Краткое резюме

## Обзор

Реализован класс `MessageCache` для кэширования сообщений диалогов в localStorage браузера. Класс обеспечивает быстрое отображение истории сообщений при переключении между диалогами без ожидания загрузки с сервера.

## Расположение

- **Файл**: `wwwroot/app.js`
- **Класс**: `MessageCache`
- **Строки**: После класса `WebSocketClient`

## Основные возможности

### 1. Проверка доступности localStorage
```javascript
checkLocalStorageAvailability()
```
- Проверяет доступность localStorage при инициализации
- Устанавливает флаг `isAvailable`
- Тихо отключает кэширование если localStorage недоступен

### 2. Получение кэшированных сообщений
```javascript
getCachedMessages(dialogueId)
```
- Загружает сообщения из localStorage для указанного диалога
- Проверяет срок действия кэша (24 часа)
- Автоматически удаляет устаревшие записи
- Возвращает `null` если кэш отсутствует или устарел

### 3. Сохранение сообщений в кэш
```javascript
cacheMessages(dialogueId, messages)
```
- Сохраняет массив сообщений в localStorage
- Автоматически вызывает `checkCacheSize()` после сохранения
- Обрабатывает `QuotaExceededError` с автоматической очисткой

### 4. Добавление одного сообщения
```javascript
addMessage(dialogueId, message)
```
- Добавляет новое сообщение к существующему кэшу
- Автоматически вызывает `trimCache()` для ограничения размера
- Сохраняет обновленный кэш

### 5. Ограничение количества сообщений
```javascript
trimCache(dialogueId, messages)
```
- Ограничивает кэш до 100 последних сообщений
- Удаляет самые старые сообщения при превышении лимита
- Вызывается автоматически в `addMessage()`

### 6. Очистка устаревшего кэша
```javascript
cleanExpiredCache()
```
- Удаляет сообщения старше 24 часов
- Удаляет поврежденные записи
- Должна вызываться при инициализации приложения

### 7. Проверка размера кэша
```javascript
checkCacheSize()
```
- Проверяет общий размер кэша (лимит 5MB)
- Автоматически удаляет самые старые записи до достижения 4MB
- Вызывается автоматически после каждого сохранения

## Конфигурация

```javascript
    this.maxMessagesPerDialogue = 100;         // Максимум сообщений на диалог

    this.ttl = 24 * 60 * 60 * 1000;            // Время жизни кэша (24 часа)

```

## Обработка ошибок

### 1. Недоступность localStorage
- Проверка при инициализации
- Тихое отключение всех операций кэширования
- Логирование предупреждения в консоль

### 2. QuotaExceededError
- Автоматическая очистка устаревшего кэша
- Повторная попытка сохранения после очистки
- Логирование ошибки если повторная попытка не удалась

### 3. Поврежденные данные
- Обработка ошибок парсинга JSON
- Автоматическое удаление поврежденных записей
- Возврат `null` вместо выброса исключения

### 4. Все операции обернуты в try-catch
- Логирование всех ошибок в консоль
- Graceful degradation при любых проблемах

## Использование в приложении

```javascript
// Инициализация (будет реализовано в задаче 12)
const messageCache = new MessageCache();

// Очистка устаревшего кэша при загрузке
messageCache.cleanExpiredCache();

// Загрузка кэшированных сообщений
const cached = messageCache.getCachedMessages(dialogueId);
if (cached) {
    displayMessages(cached); // Мгновенное отображение
}

// Загрузка обновлений с сервера в фоне
const serverMessages = await fetchMessagesFromServer(dialogueId);
if (hasChanges(cached, serverMessages)) {
    displayMessages(serverMessages);
    messageCache.cacheMessages(dialogueId, serverMessages);
}

// Добавление нового сообщения
messageCache.addMessage(dialogueId, newMessage);
```

## Производительность

- Проверка доступности: O(1)
- Получение сообщений: O(1) - прямой доступ по ключу
- Сохранение сообщений: O(n) - сериализация массива
- Обрезка кэша: O(n) - удаление элементов из начала массива
- Очистка устаревшего кэша: O(m) - перебор всех ключей localStorage
- Проверка размера: O(m) - перебор всех ключей кэша

Где:
- n - количество сообщений в диалоге
- m - количество записей кэша в localStorage
