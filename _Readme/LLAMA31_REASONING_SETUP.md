# Настройка Llama3.1:8b для рассуждений

## Изменения

### 1. Модель
Переключились на `llama3.1:8b` - поддерживает tool calling.

### 2. System Prompt
Обновлен для стимулирования рассуждений:

**Структура ответа:**
1. Understanding: "I understand you want to..."
2. Plan: "Here's my plan: Step 1... Step 2..."
3. [Tool calls]
4. Summary: "Done! I have... The result is..."

**Особенности:**
- Промпт на английском (llama3.1 лучше понимает английский)
- Модель отвечает на русском
- Поощряет step-by-step thinking
- Требует объяснения перед действием

### 3. Улучшенное логирование

**DirectShellService:**
- Подробные логи выполнения команд
- Проверка существования рабочей директории
- Автоматическая проверка создания файлов
- Информативные сообщения об успехе/ошибке

**Пример логов:**
```
=== Shell Command Execution Start ===
Command: echo Привет! > text.txt
Working Directory: D:\Projects\MyProject
Exit Code: 0
Output: (empty)
Error: (empty)
Command executed successfully
Файл 'text.txt' успешно создан в директории D:\Projects\MyProject
=== Shell Command Execution End ===
```

## Пример работы

**Запрос:**
```
Создай файл test.txt с текстом "Hello World"
```

**Ответ Llama3.1:**
```
Я понимаю, что вам нужно создать файл test.txt с содержимым "Hello World".

Мой план:
1. Использую команду Windows echo для записи текста в файл
2. Команда будет: echo Hello World > test.txt

📋 Выполнение операций:

✅ Выполнение команды:
   Файл 'test.txt' успешно создан в директории D:\Projects\MyProject

Готово! Файл test.txt создан с текстом "Hello World".
```

## Настройка

Конфигурация в `appsettings.json`:
```json
{
  "Llm": {
    "Provider": "Ollama",
    "Ollama": {
      "BaseUrl": "http://localhost:11434",
      "Model": "llama3.1:8b"
    }
  }
}
```

## Отладка

Если команды не выполняются:

1. Проверьте логи приложения
2. Убедитесь, что рабочая директория существует
3. Проверьте права доступа к директории
4. Посмотрите на Exit Code команды

Логи покажут:
- Точную команду
- Рабочую директорию
- Код выхода
- Вывод и ошибки
- Результат проверки создания файла
