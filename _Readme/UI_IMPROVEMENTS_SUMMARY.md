# Сводка улучшений UI

## Дата: 26 февраля 2026

## Реализованные функции

### 1. Валидация подключения к модели при запуске

**Описание**: Приложение теперь проверяет подключение к настроенной модели Ollama при запуске и отображает предупреждение, если модель недоступна.

**Компоненты**:
- Backend: `IStartupValidationService`, `StartupValidationService`
- API: `GET /api/startup/validate`
- Frontend: Функция `validateModelConnection()`, предупреждение в верхней части страницы

**Использование**: При запуске приложения автоматически проверяется доступность модели. Если Ollama не запущен или модель недоступна, отображается желтое предупреждение с сообщением "Нет подключения к модели {model_name}, запустите модель в Ollama".

### 2. Управление проектами через UI

**Описание**: Заменен текстовый ввод пути проекта на dropdown-селектор с возможностью управления списком проектов через модальное окно.

**Компоненты**:
- Backend: `IProjectManagementService`, `ProjectManagementService`
- Модель данных: `Project` (Id, Name, Path, AddedAt, IsSelected)
- API endpoints:
  - `GET /api/projects` - получить все проекты
  - `GET /api/projects/selected` - получить выбранный проект
  - `POST /api/projects` - добавить проект
  - `DELETE /api/projects/{id}` - удалить проект
  - `POST /api/projects/{id}/select` - выбрать проект
- Frontend: Селектор проектов, модальное окно управления

**Использование**:
1. Нажмите кнопку 📁 рядом с селектором проектов
2. В модальном окне нажмите "Добавить" и введите путь к проекту
3. Выберите проект из dropdown-списка
4. Выбранный проект сохраняется в базе данных и автоматически выбирается при следующем запуске

### 3. Ручное управление чекпойнтами

**Описание**: Удалено автоматическое создание чекпойнтов при каждом промпте. Теперь пользователь создает чекпойнты вручную по необходимости.

**BREAKING CHANGE**: Автоматические чекпойнты больше не создаются. Пользователи должны создавать чекпойнты вручную перед важными изменениями.

**Компоненты**:
- Backend: Удалена логика автоматического создания чекпойнтов из `PromptProcessor.cs`
- API: `POST /api/dialogues/{id}/checkpoints` - создать чекпойнт вручную
- Frontend: Кнопка ➕ в панели чекпойнтов, функция `createManualCheckpoint()`

**Использование**:
1. Откройте диалог
2. Нажмите кнопку ➕ в панели чекпойнтов справа
3. Введите описание чекпойнта (необязательно)
4. Чекпойнт создается и появляется в списке
5. Используйте кнопку "Откатить" для восстановления состояния проекта

## Технические детали

### База данных

Добавлена таблица `Projects`:
```sql
CREATE TABLE Projects (
    Id INTEGER PRIMARY KEY,
    Name TEXT NOT NULL,
    Path TEXT NOT NULL UNIQUE,
    AddedAt DATETIME NOT NULL,
    IsSelected BOOLEAN NOT NULL
);
```

### API Endpoints

**Валидация модели**:
- `GET /api/startup/validate` - проверка подключения к модели

**Управление проектами**:
- `GET /api/projects` - список всех проектов
- `GET /api/projects/selected` - текущий выбранный проект
- `POST /api/projects` - добавить проект (body: `{ projectPath: string }`)
- `DELETE /api/projects/{id}` - удалить проект
- `POST /api/projects/{id}/select` - выбрать проект

**Чекпойнты**:
- `POST /api/dialogues/{id}/checkpoints` - создать чекпойнт (body: `{ description?: string }`)

### Сервисы

- `IStartupValidationService` - валидация подключения к модели
- `IProjectManagementService` - управление списком проектов

## Миграция для существующих пользователей

1. **Проекты**: Старые пути проектов из localStorage больше не используются. Добавьте проекты заново через UI управления проектами.

2. **Чекпойнты**: Автоматические чекпойнты больше не создаются. Создавайте чекпойнты вручную перед важными изменениями кода.
