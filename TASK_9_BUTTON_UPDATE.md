# Обновление кнопки "Задачи"

## Изменения

### 1. Убран текст с кнопки
**Файл**: `wwwroot/index.html`

Было:
```html
<button id="tasks-button" style="display: none;">
    <span class="material-icons">assignment</span> Задачи
</button>
```

Стало:
```html
<button id="tasks-button" style="display: none;" title="Сгенерировать план">
    <span class="material-icons">assignment</span>
</button>
```

### 2. Обновлены CSS стили
**Файл**: `wwwroot/index.html`

Кнопка теперь квадратная с фиксированным размером:
```css
#tasks-button {
    padding: 12px;
    min-width: 44px;
    height: 44px;
    display: flex;
    align-items: center;
    justify-content: center;
}
```

### 3. Изменена логика отображения
**Файл**: `wwwroot/app.js`

Функция `checkAndShowTasksButton()` обновлена:

Было:
- План существует → кнопка disabled
- План не существует → кнопка активна

Стало:
- План существует → кнопка скрыта
- План не существует → кнопка показана и активна

```javascript
if (response.ok) {
    // План существует - скрываем кнопку
    tasksButton.style.display = 'none';
} else if (response.status === 404) {
    // План не существует - показываем кнопку
    tasksButton.style.display = 'flex';
    tasksButton.disabled = false;
    tasksButton.title = 'Сгенерировать план';
}
```

## Поведение

### Сценарий 1: Диалог без плана
1. Пользователь выбирает диалог из группы с заполненным Tasks
2. Система проверяет наличие плана
3. План не найден (404)
4. Кнопка появляется с иконкой 📋 и tooltip "Сгенерировать план"

### Сценарий 2: Диалог с планом
1. Пользователь выбирает диалог из группы
2. Система проверяет наличие плана
3. План найден (200 OK)
4. Кнопка полностью скрывается
5. Панель задач автоматически открывается с планом

### Сценарий 3: Диалог без группы или без Tasks
1. Пользователь выбирает диалог
2. У диалога нет группы или в группе нет Tasks
3. Кнопка скрыта

### Сценарий 4: Создание плана
1. Пользователь нажимает кнопку "Сгенерировать план"
2. План создается через API
3. После успешного создания кнопка исчезает
4. Панель задач открывается с новым планом

## UI/UX улучшения

1. **Минимализм** - только иконка, без текста
2. **Понятность** - tooltip объясняет действие
3. **Логичность** - кнопка исчезает когда план уже есть
4. **Консистентность** - размер 44x44px соответствует стандартам доступности
