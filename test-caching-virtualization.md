# Тестирование кэширования и виртуализации - Checkpoint 15

## Дата тестирования
27 февраля 2026

## Цель
Проверить работу кэширования сообщений (MessageCache) и виртуализации списка (VirtualList) в реальных условиях.

## Тестовые сценарии

### 1. Тестирование кэширования сообщений

#### 1.1 Мгновенное отображение кэшированных сообщений
**Шаги:**
1. Открыть приложение в браузере
2. Создать новый диалог
3. Отправить несколько сообщений (минимум 5)
4. Переключиться на другой диалог
5. Вернуться к первому диалогу
6. Измерить время отображения сообщений

**Ожидаемый результат:**
- Кэшированные сообщения отображаются мгновенно (< 100ms)
- В консоли браузера видны логи: `[MessageCache] Загружено X сообщений из кэша`
- Сообщения отображаются до завершения запроса к серверу

**Статус:** ⏳ Требует ручного тестирования

---

#### 1.2 Фоновая синхронизация с сервером
**Шаги:**
1. Загрузить диалог с кэшированными сообщениями
2. Открыть DevTools → Network
3. Проверить, что запрос к серверу выполняется в фоне

**Ожидаемый результат:**
- Запрос `/api/dialogues/{id}/messages` выполняется после отображения кэша
- UI не блокируется во время запроса
- Если есть новые сообщения, они добавляются без перезагрузки всего списка

**Статус:** ⏳ Требует ручного тестирования

---

#### 1.3 Ограничение размера кэша
**Шаги:**
1. Создать диалог с большим количеством сообщений (> 100)
2. Открыть DevTools → Application → Local Storage
3. Проверить размер кэша для диалога

**Ожидаемый результат:**
- В кэше хранится максимум 100 последних сообщений
- В консоли видны логи: `[MessageCache] Удалено X старых сообщений из кэша`
- Общий размер кэша не превышает 5MB

**Статус:** ⏳ Требует ручного тестирования

---

### 2. Тестирование виртуализации списка

#### 2.1 Виртуализация больших списков (>100 сообщений)
**Шаги:**
1. Создать диалог с большим количеством сообщений (рекомендуется 150-200)
2. Открыть DevTools → Elements
3. Проверить количество DOM элементов в `#message-list`
4. Прокрутить список вверх и вниз

**Ожидаемый результат:**
- В DOM отрендерены только видимые сообщения + буфер (10 сверху/снизу)
- При прокрутке элементы динамически добавляются/удаляются
- В консоли видны логи: `[VirtualList] Видимый диапазон: X - Y из Z`
- Общее количество DOM элементов значительно меньше общего количества сообщений

**Статус:** ⏳ Требует ручного тестирования

---

#### 2.2 Плавность прокрутки (визуальная проверка)
**Шаги:**
1. Открыть диалог с большим количеством сообщений (>100)
2. Быстро прокрутить список вверх и вниз
3. Обратить внимание на плавность анимации
4. Открыть DevTools → Performance
5. Записать профиль производительности во время прокрутки

**Ожидаемый результат:**
- Прокрутка плавная, без лагов и рывков
- FPS не падает ниже 30 (в идеале 60 FPS)
- В консоли нет предупреждений: `[VirtualList] Низкий FPS при прокрутке`
- Время рендеринга фрагментов < 50ms

**Статус:** ⏳ Требует ручного тестирования

---

#### 2.3 Подгрузка истории при прокрутке к началу
**Шаги:**
1. Открыть диалог с большим количеством сообщений
2. Прокрутить к концу списка
3. Быстро прокрутить к началу списка
4. Наблюдать за подгрузкой предыдущих сообщений

**Ожидаемый результат:**
- При достижении порога (20 сообщений от начала) автоматически загружаются предыдущие сообщения
- В консоли видны логи: `[VirtualList] Достигнут порог подгрузки истории`
- Позиция прокрутки сохраняется после добавления новых сообщений
- Нет "прыжков" в позиции прокрутки

**Статус:** ⏳ Требует ручного тестирования

---

### 3. Тестирование поиска по сообщениям

#### 3.1 Поиск по всем сообщениям (включая не отрендеренные)
**Шаги:**
1. Открыть диалог с большим количеством сообщений (>100)
2. Ввести поисковый запрос в поле поиска
3. Нажать кнопку "🔍 Найти"
4. Проверить результаты поиска

**Ожидаемый результат:**
- Поиск выполняется по всем сообщениям, включая не отрендеренные
- В консоли видны логи: `[VirtualList] Найдено X совпадений для "запрос"`
- Отображается информация о количестве результатов
- Прокрутка к первому результату выполняется автоматически

**Статус:** ⏳ Требует ручного тестирования

---

#### 3.2 Подсветка найденных сообщений
**Шаги:**
1. Выполнить поиск по сообщениям
2. Проверить, что найденное сообщение подсвечивается
3. Подождать 2 секунды

**Ожидаемый результат:**
- Найденное сообщение подсвечивается желтым цветом (#fff3cd)
- Подсветка исчезает через 2 секунды
- Анимация плавная (transition 0.3s)

**Статус:** ⏳ Требует ручного тестирования

---

#### 3.3 Очистка результатов поиска
**Шаги:**
1. Выполнить поиск
2. Нажать кнопку "✕ Очистить"

**Ожидаемый результат:**
- Поле поиска очищается
- Информация о результатах исчезает
- Список сообщений возвращается в нормальное состояние

**Статус:** ⏳ Требует ручного тестирования

### 4. Интеграционное тестирование

#### 4.1 Кэширование + Виртуализация
**Шаги:**
1. Создать диалог с большим количеством сообщений (>100)
2. Закрыть и снова открыть диалог
3. Проверить, что кэш загружается мгновенно
4. Проверить, что виртуализация работает с кэшированными сообщениями

**Ожидаемый результат:**
- Кэшированные сообщения отображаются мгновенно
- Виртуализация активируется для списка >50 сообщений
- Оба компонента работают без конфликтов

**Статус:** ⏳ Требует ручного тестирования

---

#### 4.2 Виртуализация + Поиск
**Шаги:**
1. Открыть диалог с большим количеством сообщений
2. Выполнить поиск по сообщению, которое находится далеко от текущей позиции
3. Проверить прокрутку к результату

**Ожидаемый результат:**
- Поиск находит сообщение даже если оно не отрендерено
- Прокрутка к результату работает корректно
- Сообщение подсвечивается после прокрутки

**Статус:** ⏳ Требует ручного тестирования

---

#### 4.3 Автопрокрутка к новым сообщениям
**Шаги:**
1. Открыть диалог
2. Прокрутить к концу списка (в пределах 100px от конца)
3. Отправить новое сообщение
4. Проверить автопрокрутку

**Ожидаемый результат:**
- Список автоматически прокручивается к новому сообщению
- В консоли: `[VirtualList] Автопрокрутка к новому сообщению`

**Шаги (альтернативный сценарий):**
1. Прокрутить к середине списка (далеко от конца)
2. Отправить новое сообщение

**Ожидаемый результат:**
- Автопрокрутка НЕ выполняется
- В консоли: `[VirtualList] Автопрокрутка пропущена - пользователь читает старые сообщения`

**Статус:** ⏳ Требует ручного тестирования

## Инструкции по тестированию

### Подготовка тестовых данных

Для создания диалога с большим количеством сообщений можно использовать следующий подход:

1. Создать новый диалог
2. Отправить команду: "Создай тестовые данные - отправь 150 коротких сообщений"
3. Или использовать скрипт в консоли браузера:

```javascript
// Скрипт для создания тестовых сообщений (выполнить в консоли браузера)
async function createTestMessages(count) {
    for (let i = 1; i <= count; i++) {
        const input = document.getElementById('prompt-input');
        input.value = `Тестовое сообщение ${i}`;
        await sendMessage();
        await new Promise(resolve => setTimeout(resolve, 1000)); // Задержка 1 секунда
    }
}

// Создать 150 тестовых сообщений
createTestMessages(150);
```

### Проверка логов в консоли

Откройте DevTools (F12) → Console и следите за логами:
- `[MessageCache]` - логи кэширования
- `[VirtualList]` - логи виртуализации
- `[Monitoring]` - логи производительности
- `[Search]` - логи поиска

### Проверка производительности

1. Откройте DevTools → Performance
2. Нажмите "Record"
3. Выполните действия (прокрутка, поиск и т.д.)
4. Остановите запись
5. Проанализируйте FPS и время рендеринга
