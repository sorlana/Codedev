# End-to-End Manual Test Plan: Model Configuration UI

## Цель
Проверить полный цикл работы функции конфигурации модели от UI до сохранения и использования.

## Предварительные условия
1. Приложение запущено (`dotnet run`)
2. Браузер открыт на `http://localhost:5000` (или другой порт из launchSettings.json)
3. Файл `appsettings.json` доступен для записи

## Тест 1: Конфигурация провайдера OpenAI

### Шаги:
1. **Открыть модальное окно конфигурации**
   - Нажать на кнопку ⚙️ в левой панели
   - ✅ Ожидаемый результат: Модальное окно открывается с двумя вкладками (Provider и Local)

2. **Проверить загрузку текущей конфигурации**
   - Проверить, что поля заполнены текущими значениями из appsettings.json
   - ✅ Ожидаемый результат: Поля содержат существующие значения

3. **Ввести новую конфигурацию провайдера**
   - Перейти на вкладку "Provider" (если не активна)
   - Ввести Base URL: `https://api.openai.com/v1`
   - Ввести API Key: `sk-test-key-12345` (проверить, что отображается как ••••••)
   - Ввести Model Name: `gpt-4`
   - ✅ Ожидаемый результат: Все поля заполнены, API key замаскирован

4. **Протестировать валидацию**
   - Очистить поле Base URL
   - Нажать "Save Provider Configuration"
   - ✅ Ожидаемый результат: Появляется сообщение об ошибке "Base URL is required", поле подсвечено красным
   - Вернуть значение Base URL

5. **Протестировать подключение (опционально)**
   - Нажать "Test Connection"
   - ✅ Ожидаемый результат: Сообщение о результате теста (успех или ошибка)

6. **Сохранить конфигурацию**
   - Нажать "Save Provider Configuration"
   - ✅ Ожидаемый результат: Сообщение "Provider configuration saved successfully" (зеленое)

7. **Проверить сохранение в файл**
   - Открыть `appsettings.json`
   - ✅ Ожидаемый результат: Секция `Llm` содержит:
     ```json
     "Llm": {
       "Provider": "OpenAI",
       "OpenAI": {
         "ApiKey": "sk-test-key-12345",
         "Model": "gpt-4",
         "BaseUrl": "https://api.openai.com/v1"
       }
     }
     ```

8. **Проверить применение конфигурации без перезапуска**
   - Закрыть модальное окно
   - Снова открыть модальное окно
   - ✅ Ожидаемый результат: Поля содержат только что сохраненные значения

9. **Проверить использование конфигурации**
   - Создать новый диалог
   - Отправить сообщение LLM
   - ✅ Ожидаемый результат: Запрос отправляется с использованием новой конфигурации OpenAI

## Тест 2: Конфигурация локального Ollama

### Шаги:
1. **Открыть модальное окно конфигурации**
   - Нажать на кнопку ⚙️

2. **Переключиться на вкладку Local**
   - Нажать на вкладку "Local"
   - ✅ Ожидаемый результат: Отображаются поля для Ollama URL и Model

3. **Ввести URL Ollama**
   - Ввести Ollama URL: `http://localhost:11434`

4. **Загрузить список моделей**
   - Нажать "Refresh Models"
   - ✅ Ожидаемый результат: 
     - Если Ollama запущен: Dropdown заполняется доступными моделями
     - Если Ollama не запущен: Сообщение об ошибке подключения

5. **Выбрать модель**
   - Выбрать модель из dropdown (например, "llama2")
   - ✅ Ожидаемый результат: Модель выбрана

6. **Протестировать валидацию**
   - Очистить поле Ollama URL
   - Нажать "Save Local Configuration"
   - ✅ Ожидаемый результат: Ошибка валидации "Ollama URL is required"

7. **Сохранить конфигурацию Ollama**
   - Вернуть URL
   - Нажать "Save Local Configuration"
   - ✅ Ожидаемый результат: Сообщение "Local configuration saved successfully"

8. **Проверить сохранение в файл**
   - Открыть `appsettings.json`
   - ✅ Ожидаемый результат: Секция `Llm` содержит:
     ```json
     "Llm": {
       "Provider": "Ollama",
       "Ollama": {
         "BaseUrl": "http://localhost:11434",
         "Model": "llama2"
       }
     }
     ```

9. **Проверить переключение провайдера**
   - Перезагрузить страницу
   - Открыть модальное окно
   - ✅ Ожидаемый результат: Активна вкладка "Local", поля заполнены сохраненными значениями

## Тест 3: Закрытие модального окна

### Шаги:
1. **Закрыть кнопкой X**
   - Открыть модальное окно
   - Нажать кнопку × в правом верхнем углу
   - ✅ Ожидаемый результат: Модальное окно закрывается

2. **Закрыть кликом на overlay**
   - Открыть модальное окно
   - Кликнуть на затемненную область вне модального окна
   - ✅ Ожидаемый результат: Модальное окно закрывается

3. **Закрыть клавишей Escape**
   - Открыть модальное окно
   - Нажать клавишу Escape
   - ✅ Ожидаемый результат: Модальное окно закрывается

## Тест 4: Переключение между вкладками

### Шаги:
1. **Заполнить поля на вкладке Provider**
   - Открыть модальное окно
   - Заполнить все поля на вкладке Provider

2. **Переключиться на вкладку Local**
   - Нажать на вкладку "Local"
   - ✅ Ожидаемый результат: Отображаются поля Ollama

3. **Вернуться на вкладку Provider**
   - Нажать на вкладку "Provider"
   - ✅ Ожидаемый результат: Ранее введенные значения сохранились

## Тест 5: Валидация URL

### Шаги:
1. **Ввести невалидный URL**
   - Открыть модальное окно
   - Ввести в Base URL: `not-a-url`
   - Нажать "Save Provider Configuration"
   - ✅ Ожидаемый результат: Ошибка "Invalid URL format"

2. **Ввести URL без протокола**
   - Ввести в Base URL: `api.openai.com`
   - Нажать "Save Provider Configuration"
   - ✅ Ожидаемый результат: Ошибка валидации URL

3. **Ввести валидный URL**
   - Ввести в Base URL: `https://api.openai.com/v1`
   - ✅ Ожидаемый результат: Валидация проходит
