# Быстрый старт: E2E тестирование UI Integration

## Подготовка (5 минут)

### 1. Создать тестовую директорию

```bash
# Создать тестовую директорию
mkdir C:\TestProjects\UIAgentTest
cd C:\TestProjects\UIAgentTest

# Инициализировать Git
git init
git config user.name "Test User"
git config user.email "test@example.com"

# Создать простой C# проект
dotnet new console -n TestProject
```

### 2. Создать тестовые файлы tasks.md

**C:\TestProjects\UIAgentTest\tasks.md:**
```markdown
# Тестовые задачи

- [ ] 1. Создать файл test.txt
  - Создать файл test.txt с текстом "Hello from task 1"
  
- [ ] 2. Создать файл test2.txt
  - Создать файл test2.txt с текстом "Hello from task 2"
  
- [ ] 3. Создать файл test3.txt
  - Создать файл test3.txt с текстом "Hello from task 3"
```

**C:\TestProjects\UIAgentTest\.kiro\specs\feature\tasks.md:**
```bash
# Создать директорию
mkdir -p .kiro\specs\feature

# Создать файл
echo "# Задачи спецификации

- [ ] 1. Создать файл spec-test.txt
  - Создать файл spec-test.txt с текстом 'Spec task completed'" > .kiro\specs\feature\tasks.md
```

### 3. Запустить приложение

```bash
# В директории CSharpRefactoringAssistant
dotnet run
```

Открыть браузер: http://localhost:5000

## Быстрые тесты (10 минут)

### Тест 1: Базовый цикл (2 минуты)

1. Создать диалог "Quick Test"
2. Указать путь: `C:\TestProjects\UIAgentTest`
3. Ввести: `начни выполнение задач из tasks.md`
4. **Проверить:**
   - ✅ Кнопка "Остановить" появилась
   - ✅ Индикатор "🔄 Выполняется..."
   - ✅ Сообщения о прогрессе появляются
   - ✅ После завершения: "🎉 Все задачи выполнены"

### Тест 2: Остановка/Возобновление (2 минуты)

1. Создать новый диалог "Stop/Resume Test"
2. Ввести: `start execution from tasks.md`
3. Через 10 секунд нажать "Остановить"
4. **Проверить:**
   - ✅ Сообщение "⏸️ Выполнение остановлено"
   - ✅ Кнопка "Возобновить" появилась

6. **Проверить:**

## Если что-то не работает

### Проблема: Кнопки не появляются

**Решение:**
1. Проверить, что HTML элементы добавлены в index.html
2. Проверить CSS стили
3. Открыть DevTools → Elements → найти #execution-controls

### Проблема: Polling не работает

**Решение:**
1. Открыть DevTools → Network
2. Проверить запросы к /api/dialogues/{id}/execution-status
3. Проверить консоль на ошибки JavaScript

### Проблема: Команды не распознаются

**Решение:**
1. Проверить логи сервера
2. Проверить, что CommandRecognizer зарегистрирован в DI
3. Проверить, что PromptProcessor использует CommandRecognizer

### Проблема: Файл tasks.md не найден

**Решение:**
1. Проверить путь к проекту в диалоге
2. Проверить, что tasks.md существует
3. Проверить права доступа к файлу
