# Диагностика проблем WebSocket

## Проблема: WebSocket закрывается с кодом 1006

Код ошибки 1006 означает "abnormal closure" - соединение было закрыто без нормального handshake. Это может происходить по нескольким причинам.

## Шаги диагностики

### 1. Проверка существования диалога

Запустите скрипт для проверки диалогов в базе данных:

```powershell
.\check-dialogues.ps1
```

Скрипт покажет:
- Список всех диалогов в базе данных
- Количество сообщений в каждом диалоге
- Предложит создать тестовый диалог, если их нет

### 2. Тестирование WebSocket подключения

Откройте тестовую страницу в браузере:

```
http://localhost:5111/test-websocket-connection.html
```

Эта страница позволяет:
- Подключиться к WebSocket с указанным Dialogue ID
- Увидеть детальные логи всех событий
- Отправить тестовые сообщения (ping, user_message)
- Проверить получение `connection_ack` от сервера

### 3. Проверка логов сервера

Запустите приложение и следите за логами в консоли:

```powershell
dotnet run
```

При попытке подключения WebSocket вы должны увидеть:

```
[Timestamp] WebSocket запрос получен: Path=/ws, Query=?dialogueId=1
[Timestamp] Проверка существования диалога: DialogueId=1
[Timestamp] Диалог найден, принятие WebSocket соединения: DialogueId=1
[Timestamp] WebSocket соединение установлено: ConnectionId=..., DialogueId=1
[Timestamp] Отправлено connection_ack: ConnectionId=..., DialogueId=1
```

Если вы видите:
```
[Timestamp] Диалог не найден: DialogueId=1
```

Значит, диалог с указанным ID не существует. Создайте его через UI или используйте скрипт `check-dialogues.ps1`.

### 4. Проверка в основном приложении

1. Откройте приложение: `http://localhost:5111`
2. Создайте новый диалог или выберите существующий
3. Откройте консоль разработчика (F12)
4. Отправьте сообщение
5. Проверьте логи в консоли:

```javascript
[WebSocket] Подключение к ws://localhost:5111/ws?dialogueId=1...
[WebSocket] Соединение установлено
[WebSocket] Получено сообщение: {type: "connection_ack", ...}
```

## Типичные проблемы и решения

### Проблема 1: Диалог не найден

**Симптомы:**
- WebSocket закрывается сразу после подключения
- В логах сервера: "Диалог не найден"

**Решение:**
1. Проверьте, что диалог существует: `.\check-dialogues.ps1`
2. Создайте тестовый диалог через скрипт или UI
3. Используйте правильный Dialogue ID при подключении

### Проблема 2: Приложение не перезапущено

**Симптомы:**
- Изменения в коде не применяются
- WebSocket не работает после обновления кода

**Решение:**
1. Остановите приложение (Ctrl+C)
2. Пересоберите: `dotnet build`
3. Запустите снова: `dotnet run`

### Проблема 3: Порт занят или неверный

**Симптомы:**
- Не удается подключиться к WebSocket
- Ошибка "Connection refused"

**Решение:**
1. Проверьте, что приложение запущено на порту 5111
2. Проверьте `Properties/launchSettings.json` для подтверждения порта
3. Убедитесь, что в URL используется правильный порт

### Проблема 4: Браузер блокирует WebSocket

**Симптомы:**
- WebSocket не подключается в определенном браузере
- Работает в одном браузере, но не в другом

**Решение:**
1. Проверьте настройки безопасности браузера
2. Отключите расширения, которые могут блокировать WebSocket
3. Попробуйте в режиме инкогнито
4. Проверьте, что используется `ws://` (не `wss://`) для localhost

## Дополнительная диагностика

### Проверка WebSocket в Chrome DevTools

1. Откройте DevTools (F12)
2. Перейдите на вкладку "Network"
3. Фильтр: "WS" (WebSocket)
4. Обновите страницу или подключитесь к диалогу
5. Кликните на WebSocket соединение
6. Вкладка "Messages" покажет все отправленные/полученные сообщения
7. Вкладка "Headers" покажет детали handshake

### Логирование в режиме отладки

Включите режим отладки в `app.js`:

```javascript
window.DEBUG_MODE = true;
```

Это включит дополнительное логирование:
- Детальные логи WebSocket событий
- Метрики производительности (TTFB, FPS)
- Информация о кэше
- Статус соединения

## Следующие шаги

Если проблема не решена после выполнения всех шагов:

1. Соберите логи:
   - Логи сервера (консоль)
   - Логи браузера (DevTools Console)
   - Логи WebSocket (DevTools Network -> WS)

2. Проверьте версии:
   - .NET SDK: `dotnet --version`
   - Браузер и его версия

3. Попробуйте тестовую страницу для изоляции проблемы
