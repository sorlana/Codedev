🧪 Тестирование кэширования и виртуализации - Checkpoint 15

ℹ️ Информация: Этот документ содержит подробные инструкции для ручного тестирования функций кэширования (MessageCache) и виртуализации (VirtualList). Перед началом тестирования убедитесь, что приложение запущено на http://localhost:5000

1️⃣ Тестирование кэширования сообщений

1.1 Мгновенное отображение кэшированных сообщений ⏳ Ожидает

📋 Шаги тестирования:

  1. Откройте приложение в браузере
  2. Создайте новый диалог
  3. Отправьте 5-10 сообщений
  4. Переключитесь на другой диалог (или создайте новый)
  5. Вернитесь к первому диалогу
  6. Откройте DevTools (F12) → Console
  7. Наблюдайте за временем отображения

✅ Ожидаемый результат:

  • Сообщения отображаются мгновенно (< 100ms)
  • В консоли: [MessageCache] Загружено X сообщений из кэша
  • Сообщения видны до завершения запроса к серверу

1.2 Фоновая синхронизация с сервером ⏳ Ожидает

📋 Шаги тестирования:

  1. Загрузите диалог с кэшированными сообщениями
  2. Откройте DevTools → Network
  3. Проверьте запросы к /api/dialogues/{id}/messages

✅ Ожидаемый результат:

  • Запрос выполняется после отображения кэша
  • UI не блокируется
  • Новые сообщения добавляются плавно

1.3 Ограничение размера кэша ⏳ Ожидает

📋 Шаги тестирования:

  1. Создайте диалог с > 100 сообщениями
  2. Откройте DevTools → Application → Local Storage
  3. Найдите ключ msg_cache_{dialogueId}
  4. Проверьте количество сообщений в кэше

✅ Ожидаемый результат:

  • Максимум 100 сообщений в кэше
  • В консоли: [MessageCache] Удалено X старых сообщений
  • Общий размер кэша < 5MB

2️⃣ Тестирование виртуализации списка

2.1 Виртуализация больших списков (>100 сообщений) ⏳ Ожидает

📋 Шаги тестирования:

  1. Создайте диалог с 150-200 сообщениями
  2. Откройте DevTools → Elements
  3. Проверьте количество .message элементов в DOM
  4. Прокрутите список вверх и вниз
  5. Наблюдайте за изменениями в DOM

✅ Ожидаемый результат:

  • В DOM только видимые элементы + буфер (≈20-30 элементов)
  • При прокрутке элементы добавляются/удаляются
  • В консоли: [VirtualList] Видимый диапазон: X - Y из Z

2.2 Плавность прокрутки ⏳ Ожидает

📋 Шаги тестирования:

  1. Откройте диалог с > 100 сообщениями
  2. Быстро прокрутите список вверх и вниз
  3. Обратите внимание на плавность
  4. Откройте DevTools → Performance
  5. Запишите профиль во время прокрутки

✅ Ожидаемый результат:

  • Прокрутка плавная, без лагов
  • FPS ≥ 30 (в идеале 60)
  • Нет предупреждений о низком FPS в консоли

2.3 Подгрузка истории при прокрутке к началу ⏳ Ожидает

📋 Шаги тестирования:

  1. Откройте диалог с большим количеством сообщений
  2. Прокрутите к концу списка
  3. Быстро прокрутите к началу
  4. Наблюдайте за подгрузкой

✅ Ожидаемый результат:

  • При достижении порога загружаются предыдущие сообщения
  • В консоли: [VirtualList] Достигнут порог подгрузки истории
  • Позиция прокрутки сохраняется

3️⃣ Тестирование поиска по сообщениям

3.1 Поиск по всем сообщениям ⏳ Ожидает

📋 Шаги тестирования:

  1. Откройте диалог с > 100 сообщениями
  2. Введите поисковый запрос
  3. Нажмите "🔍 Найти"
  4. Проверьте результаты

✅ Ожидаемый результат:

  • Поиск по всем сообщениям (включая не отрендеренные)
  • В консоли: [VirtualList] Найдено X совпадений
  • Автоматическая прокрутка к первому результату

3.2 Подсветка найденных сообщений ⏳ Ожидает

📋 Шаги тестирования:

  1. Выполните поиск
  2. Проверьте подсветку результата
  3. Подождите 2 секунды

✅ Ожидаемый результат:

  • Сообщение подсвечивается желтым (#fff3cd)
  • Подсветка исчезает через 2 секунды
  • Плавная анимация

4️⃣ Интеграционное тестирование

4.1 Кэширование + Виртуализация ⏳ Ожидает

📋 Шаги тестирования:

  1. Создайте диалог с > 100 сообщениями
  2. Закройте и снова откройте диалог
  3. Проверьте работу обоих компонентов

✅ Ожидаемый результат:

  • Кэш загружается мгновенно
  • Виртуализация активна для списка > 50
  • Нет конфликтов между компонентами

4.2 Автопрокрутка к новым сообщениям ⏳ Ожидает

📋 Шаги тестирования:

  1. Прокрутите к концу списка (в пределах 100px)
  2. Отправьте новое сообщение
  3. Проверьте автопрокрутку
  4. Затем прокрутите к середине списка
  5. Отправьте еще одно сообщение

✅ Ожидаемый результат:

  • Сценарий 1: Автопрокрутка выполняется
  • Сценарий 2: Автопрокрутка НЕ выполняется
  • Соответствующие логи в консоли

5️⃣ Graceful Degradation

5.1 Работа без localStorage ⏳ Ожидает

📋 Шаги тестирования:

  1. Откройте браузер в режиме инкогнито
  2. Откройте приложение
  3. Создайте диалог и отправьте сообщения

✅ Ожидаемый результат:

  • Приложение работает без кэширования
  • В консоли: [MessageCache] localStorage недоступен
  • Функциональность не нарушена
